# Oakmere Landscape Studio

Fictional portfolio landing page. Static site: open `index.html` or deploy the folder to any static host (GitHub Pages, Netlify, Vercel).

- `index.html`: all HTML, CSS and JS
- `images/`: AI-generated project images (fictional concept work)

The inquiry form has no backend. It prepares a WhatsApp message; replace the placeholder number in the `wa.me` link in `index.html`.
